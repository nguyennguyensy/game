# vocablab

Website học từ vựng responsive với flashcard, game mưa từ vựng và workspace admin.

## Chạy local

```bash
npm install
npm run dev
```

Mở `http://localhost:5173` hoặc cổng Vite hiển thị trong terminal.

## Build

```bash
npm run build
```

GitHub owner/repo được cấu hình trong `src/config.ts`. Dữ liệu mẫu nằm tại `public/data/tree.json`.
